# Para Dulce 🌹

- Añade tu única foto a esta carpeta con el nombre **foto.jpg**, o cambia `CONFIG.foto` al principio del script de `index.html`.
- En ese mismo objeto `CONFIG` puedes cambiar el nombre, la frase, el mensaje y el nombre del archivo de música. Ya se incluye `musica.mp3`.
- Abre **index.html** con doble clic. Toca una rosa para ver la foto; la música comienza con el primer toque y se controla con ♪.
- La foto es fija: quien abra la página no puede cambiarla. Para usar otra, reemplaza **foto.jpg** en la carpeta.
- Para compartir la página, sube esta carpeta (HTML, foto y música) a **Netlify Drop**, **GitHub Pages** o **Vercel**, y comparte el enlace.

No requiere paquetes. El único recurso externo opcional es Google Fonts (Playfair Display y Great Vibes); sin conexión usa fuentes de respaldo y el resto funciona localmente. Respeta la preferencia de movimiento reducido del dispositivo.
